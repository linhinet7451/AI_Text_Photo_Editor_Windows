# AI 文字修圖工具（本機版）

在本機以文字指示修圖的 Gradio 工具：上傳照片、在瀏覽器裡塗遮罩、輸入中文指示，即可換衣服、改背景、改風格。所有運算都在自己的電腦上進行，不上傳雲端。

## 核心理念

1. **遮罩就是「指定哪裡能改、哪裡不准動」的工具**：有塗遮罩時，沒塗到的區域由程式**逐位元貼回原圖**，絕不變形、不糊化——這是合成方式的架構保證，不是看模型運氣。輸出維持原圖完整解析度，只有遮罩範圍內會被重畫（局部裁切＋合成回貼）。
2. **不用遮罩也可以**：遮罩留空即「全圖模式」，任何提示都能改整張圖；但全圖重繪時臉部、手部等細節的保真風險較高，建議先用遮罩模式比對效果。
3. **中文提示會自動翻譯**：SD 1.5 的文字理解只支援英文，本工具會先用離線翻譯模型（Helsinki-NLP/opus-mt-zh-en）把中文翻成英文再送出，中英混寫也可以；執行資訊會同時顯示原文與實際送出的 prompt。

## 快速開始（Windows）

1. 雙擊 `install.bat`（依序找 Python 3.11 / 3.12 / 3.13，建立 venv 並安裝 `requirements.txt` 鎖定版本的套件）。
2. 雙擊 `start.bat`，瀏覽器會自動打開 http://127.0.0.1:7860 。
3. 第一次開啟會自動背景下載並預載模型（數 GB），「模型狀態」欄位會顯示進度；第一次用中文指示時會再下載翻譯模型（約 300 MB）。

## 使用方式

1. 上傳原始照片——它會自動成為遮罩編輯器的底圖。
2. 用白色筆刷塗出要修改的區域（塗錯可用橡皮擦）；也可以改上傳小畫家做的遮罩圖（白＝要改、黑＝保留），編輯器有塗鴉時以編輯器為準。
3. 輸入修圖指示與保留內容（中文即可），視需要調整步數、強度、處理解析度（512–1024，預設 768）、一次生成張數（1–4）與 seed。
4. 按「開始修圖」。每張結果會自動存到 `outputs/`：`edit_日期_時間_序號.png` ＋同名 `.json`（含該張的 prompt、seed 與參數，可重現）。

## 硬體與耗時

- 有 NVIDIA 顯卡會用 GPU；沒有（例如 AMD 內顯）則用 CPU。
- CPU 模式下處理解析度 512 約數分鐘起一張，768 / 1024 更久，可以掛著跑，介面會顯示步數進度。
- 品質優先建議：遮罩模式 + 處理解析度 768、步數 25–35。遮罩模式只重算塗抹區域附近，未編輯區維持原圖畫質。

## 模型清單

- 預設：`stable-diffusion-v1-5/stable-diffusion-inpainting`（SD 1.5 Inpainting，公開可下載；舊 runwayml 位址已搬家）。可用環境變數 `MODEL_ID` 覆寫。
- 已移除 `stabilityai/stable-diffusion-2-inpainting`：該模型為 gated 授權模型，本工具無登入流程，選了只會下載失敗。
- 不提供 SDXL：其管線在 CPU 模式需以 fp32 載入，記憶體需求超過 16GB RAM 筆電可負擔範圍。
