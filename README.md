# AI 文字修圖工具（本機版）

在本機以文字指示修圖的 Gradio 工具，雙分頁介面：**照片修圖**（上傳照片、塗遮罩、輸入中文指示，即可換衣服、改背景、改風格）與**影片換人**（介面與選人流程已備，生成待雲端串接）。照片修圖可在本機運算，或切換到自己租的雲端 GPU worker 執行。

## 核心理念

1. **遮罩就是「指定哪裡能改、哪裡不准動」的工具**：有塗遮罩時，沒塗到的區域由程式**逐位元貼回原圖**，絕不變形、不糊化——這是合成方式的架構保證，不是看模型運氣。輸出維持原圖完整解析度，只有遮罩範圍內會被重畫（局部裁切＋合成回貼）。
2. **不用遮罩也可以**：遮罩留空即「全圖模式」，任何提示都能改整張圖；但全圖重繪時臉部、手部等細節的保真風險較高，建議先用遮罩模式比對效果。
3. **中文提示會自動翻譯**：SD 1.5 的文字理解只支援英文，本工具會先用離線翻譯模型（Helsinki-NLP/opus-mt-zh-en）把中文翻成英文再送出，中英混寫也可以；執行資訊會同時顯示原文與實際送出的 prompt。

## 快速開始（Windows）

1. 雙擊 `install.bat`（依序找 Python 3.11 / 3.12 / 3.13，建立 venv 並安裝 `requirements.txt` 鎖定版本的套件）。
2. 雙擊 `start.bat`，瀏覽器會自動打開 http://127.0.0.1:7860 。
3. 第一次開啟會自動背景下載並預載模型（數 GB），「模型狀態」欄位會顯示進度；第一次用中文指示時會再下載翻譯模型（約 300 MB）。

## 使用方式（照片修圖）

主流程只有三步，其餘參數都收在「進階設定」且已預先調校好（見下節）：

1. **① 上傳照片**——它會自動成為遮罩編輯器的底圖。
2. **② 塗遮罩**——用白色筆刷塗出要修改的區域（塗錯可用橡皮擦）；或勾「全圖遮罩」整張重繪；也可以改上傳小畫家做的遮罩圖（白＝要改、黑＝保留，收在進階設定），編輯器有塗鴉時以編輯器為準。
3. **③ 輸入修圖指示**（中文即可，會自動翻譯）→ 按「開始修圖」。

生成途中若發現參數設錯，按「開始修圖」旁的「取消生成」即可立刻中止（本機與雲端模式都支援）：不會存半成品，畫面會回到可再次生成的狀態。

每張結果會自動存到 `outputs/`：`edit_日期_時間_序號.png` ＋同名 `.json`（含該張的 prompt、seed 與參數，可重現）。

編輯模式另有「指令編輯（免遮罩・雲端）」：需雲端 worker 啟用 `capabilities.instruction` 後自動可用，本機選用會直接說明原因（見「自由度與限制」）。

## 自由度與限制（本機調校預設）

本機參數已依目標電腦（Ryzen 5 7640HS／16GB RAM／CPU）調校為「最重視符合指示」的一組預設——最高優先是產出符合 prompt 的內容，時間換品質：

- 修改強度 **1.0**（遮罩內完全重畫，prompt 才壓得過原圖）、Guidance **11**（SD 1.5 強跟隨區間）、步數 **50**、Scheduler **DPM++ 2M Karras**
- 處理解析度 **512**（SD 1.5 原生解析度、結構最穩、CPU 最快；滑桿 384–1024 可調）、一次生成 **2 張**挑選、Seed **-1** 隨機
- Negative 為加強版（deformed hands、censored、mosaic 等），刻意不放衣物相關詞以免與換裝 prompt 打架

參數仍可在「進階設定」調整，只是先調好不用自己摸索。

- **本機**＝遮罩修圖＋全圖遮罩重繪：開放權重模型在本機運行、無平台審查；限制是 SD 1.5 世代的結構理解——姿勢類改動需用全圖遮罩＋上述預設＋多抽幾張挑選（全圖重繪時未編輯區不再逐位元保證、臉手可能變形）。
- **雲端**＝日後串接指令編輯模型（Qwen-Image-Edit 等）後可免遮罩全圖指令編輯，同為自租主機上的開放權重、無平台過濾；worker 的 `capabilities.instruction` 即為其開關，串接後自動啟用。

## 本機／雲端切換

頁面上方「運算位置」可切本機／雲端。雲端模式把工作送到自租 GPU 主機上的 `worker.py`（FastAPI，只聽 127.0.0.1:8001）：

1. 雲端主機：`pip install -r requirements.txt` ＋ `pip install -r requirements-worker.txt`（worker 額外套件，主程式不需要），再 `WORKER_TOKEN=<密鑰> python worker.py`。
2. 本機在「雲端設定」填執行個體 ID 按「建立隧道」（`ssh -N -L 8001:127.0.0.1:8001 -p 2222 pod-<ID>@ssh.gputw.ai`），填 Worker 網址與相同 Token 後按「測試連線」。
3. 設定（網址／Token／執行個體 ID／運算位置）持久化於程式同層 `settings.json`（僅本機保存、勿外流）。雲端成品一樣存回本機 `outputs/`，執行資訊標示 `backend=cloud`。

## 影片換人（分頁二）

上傳 ≤65 秒影片 → 上傳人物照片 → 在抽出的幀上點選要替換的人（顯示座標百分比）→ 選 480p／720p 與保留原音。目前介面與選人驗證已完成；實際生成需雲端 GPU 且 worker 影片功能（Wan 2.2 Animate＋SAM2）串接後啟用，`capabilities.video` 目前為 false，按下生成會說明原因。

## 硬體與耗時

- 有 NVIDIA 顯卡會用 GPU；沒有（例如 AMD 內顯）則用 CPU。
- CPU 模式下預設參數（512／50 步／2 張）約數分鐘起一輪，可以掛著跑，介面會顯示步數進度；調高處理解析度會明顯更久。
- 遮罩模式只重算塗抹區域附近，未編輯區維持原圖畫質。

## 模型清單

- 預設：`stable-diffusion-v1-5/stable-diffusion-inpainting`（SD 1.5 Inpainting，公開可下載；舊 runwayml 位址已搬家）。可用環境變數 `MODEL_ID` 覆寫。
- 已移除 `stabilityai/stable-diffusion-2-inpainting`：該模型為 gated 授權模型，本工具無登入流程，選了只會下載失敗。
- 不提供 SDXL：其管線在 CPU 模式需以 fp32 載入，記憶體需求超過 16GB RAM 筆電可負擔範圍。
