AI 文字修圖工具（本機版）
==========================

用途
----
本工具是雙分頁介面：

【分頁一：照片修圖】主流程只有三步——
① 上傳照片（會自動成為遮罩編輯器的底圖）
② 在照片上塗遮罩（白色筆刷；也可改上傳遮罩圖，收在「進階設定」）
③ 輸入中文修圖指示（會自動翻譯成英文再送給模型）
然後按「開始修圖」，結果會顯示在下方並自動存檔到 outputs 資料夾。
生成途中若發現參數設錯，按「開始修圖」旁的「取消生成」即可立刻中止
（本機與雲端模式都支援）：不會存半成品，畫面會回到可再次生成的狀態。
其餘參數（保留內容、Negative、步數、強度、解析度、seed 等）都收在
「進階設定」裡，而且已經依你的電腦調校好預設值（見「自由度與限制」），
平常不用動。

編輯模式有兩種：
- 遮罩修圖（預設）：塗哪裡改哪裡，見下方核心理念。
- 指令編輯（免遮罩・雲端）：直接用一句話描述整張圖要改成什麼樣子，
  不用塗遮罩。需要雲端 GPU 且 worker 載入指令編輯模型後才會啟用
  （見「本機／雲端切換」與「自由度與限制」）；本機選了會直接說明原因。

【分頁二：影片換人】見下方專節。

運算位置（本機／雲端）
----------------------
頁面上方有「運算位置」開關：
- 本機：就在這台電腦上跑（沒有 NVIDIA 顯卡時用 CPU，較慢）。
- 雲端：把修圖工作送到你自己租的雲端 GPU 主機上的 worker 執行，
  結果再傳回來存進本機的 outputs（執行資訊會標示 backend=cloud）。

雲端使用步驟（等你註冊好 GPUtw 並儲值後照做即可）：
1. 在雲端主機上準備 worker：
   pip install -r requirements.txt
   pip install -r requirements-worker.txt
   WORKER_TOKEN=自訂一組密鑰 python worker.py
   （worker 只聽 127.0.0.1:8001，不直接對外開放。）
   requirements-worker.txt 是 worker 額外需要的 FastAPI／uvicorn 等套件，
   主程式本身不需要它。
2. 在本機建立 SSH 隧道：展開頁面上方的「雲端設定」，填入 GPUtw 的
   執行個體 ID 後按「建立隧道」（等同執行
   ssh -N -L 8001:127.0.0.1:8001 -p 2222 pod-<執行個體ID>@ssh.gputw.ai）；
   不用時按「關閉隧道」。
3. 在「雲端設定」填 Worker 網址（預設 http://127.0.0.1:8001）與認證 Token
   （必須與 worker 啟動時的 WORKER_TOKEN 完全相同），按「測試連線」
   確認能讀到 worker 的裝置／模型／功能狀態。
4. 把「運算位置」切到雲端，之後修圖就會送去雲端執行。
設定的保存：Worker 網址、Token、執行個體 ID 與運算位置會存到程式同層的
settings.json，下次開啟自動帶入（這個檔案只留在你自己的電腦，不要外流）。

影片換人（分頁二）
------------------
流程：上傳約 1 分鐘的影片（最長 65 秒，超過會友善提示）→ 上傳人物照片
→ 工具會抽出影片中間的一幀，點一下畫面中「要被替換的那個人」
（會顯示紅色標記與「已選擇位置 (x%, y%)」）→ 選解析度（480p／720p）
與是否保留原音。
目前狀態：介面、時長驗證與選人流程都已完成可用；實際生成需要雲端 GPU，
且 worker 的影片功能（Wan 2.2 Animate 角色替換＋SAM2 點選追蹤）串接後
才會啟用——目前 worker 回報 capabilities.video=false，按下生成鈕會說明
原因，不會假裝在跑。本機無法執行影片換人。

核心理念（先講清楚，免得期待落差）
----------------------------------
1. 遮罩就是「指定哪裡能改、哪裡不准動」的工具：
   有塗遮罩時，沒塗到的區域由程式逐位元貼回原圖，絕不變形、不糊化
   ——這是合成方式的架構保證，不是看模型運氣。
   輸出會維持原圖的完整解析度，只有遮罩範圍內會被重畫。
2. 不用遮罩也可以：遮罩留空就是「全圖模式」，任何提示都能改整張圖；
   但全圖重繪時，臉部、手部等細節的保真風險較高，
   建議先用遮罩模式比對效果，滿意再視需要嘗試全圖模式。
3. 中文提示會自動翻譯：修圖模型（SD 1.5）的文字理解只支援英文，
   本工具會先用離線翻譯模型把中文指示翻成英文再送出，
   任何中文描述都能送達模型；中英混寫也可以，英文片段會原樣保留。
   （執行資訊裡會同時顯示你輸入的原文與實際送出的 prompt。）

自由度與限制
------------
本機模式的參數已依你的電腦（Ryzen 5 7640HS／16GB RAM／CPU）調校為
「最重視符合指示」的一組預設，最高優先是產出符合 prompt 的內容，
時間長短不計較（生成較慢屬正常）：
- 修改強度 1.0：遮罩內完全重畫，prompt 才壓得過原圖內容（符合指示的第一關鍵）
- Guidance 11：SD 1.5 的強跟隨區間（10~12），讓模型更聽話（第二關鍵）
- 推論步數 50、Scheduler 換成 DPM++ 2M Karras（高 Guidance 下收斂較穩）
- 處理解析度 512：SD 1.5 的原生解析度，結構最穩、CPU 也最快；
  滑桿範圍 384~1024，想更精細可以自己往上調
- 一次生成 2 張、Seed -1 隨機：一次出兩張挑最符合的一張
- Negative 已加強常見失敗抑制（deformed hands、censored、mosaic 等），
  刻意不放任何衣物相關詞，避免跟換裝類 prompt 打架
這些參數都還留在「進階設定」裡可調，只是先幫你調好，不用自己摸索。

自由度：
- 本機＝遮罩修圖＋「全圖遮罩」一鍵全圖重繪。模型是開放權重、在你自己
  電腦上運行，沒有任何平台審查或內容過濾，能改到什麼程度只看模型能力。
  限制在於 SD 1.5 世代對「結構」的理解：換裝、換背景很可靠；改姿勢這類
  結構型改動，請用「全圖遮罩」＋上面的調校預設，並一次多抽幾張挑選，
  成功率比只塗局部遮罩高得多（局部遮罩在幾何上就鎖死了新姿勢）。
  全圖遮罩的代價：未編輯區不再逐位元保證原樣，臉與手可能變形。
- 雲端＝日後串接指令編輯模型（如 Qwen-Image-Edit）後，可免遮罩直接以
  指令編輯整張圖，自由度最高；同樣是自租主機上的開放權重模型、
  無平台過濾。worker 健康檢查回報的 capabilities.instruction 就是這個
  功能的開關：目前為 false（尚未串接），串接完成後會自動變 true，
  介面的「指令編輯」模式就會直接可用，不用再改程式。

適合的用途
----------
- 換衣服（例如襯衫、西裝、外套、裙子）
- 改背景（例如咖啡廳、街景、室內攝影棚）
- 改風格（例如寫實、時尚雜誌感）
- 小範圍修圖（例如改掉衣服顏色、改配件）

不一定理想的情況
----------------
- 需要極高精度的人像保真（遮罩外保證不變，但遮罩內的臉、手大改仍受模型世代上限影響）
- 需要直接參考另一張衣服照片精準試穿
- 需要在沒有遮罩的情況下只精準改某一小塊（請改用遮罩指定範圍）

第一次安裝
----------
1. 雙擊 install.bat（會依序找 Python 3.11、3.12、3.13 建立虛擬環境並安裝鎖定版本的套件）
2. 安裝完成後，雙擊 start.bat
3. Chrome 會自動打開 http://127.0.0.1:7860

首次啟動注意事項
----------------
- 第一次開啟頁面時會自動在背景下載並預載修圖模型（數 GB），
  「進階設定」裡的「模型狀態」欄位會顯示進度；也可以按「預先載入模型」手動觸發。
- 第一次使用中文指示時，還會下載離線翻譯模型（約 300 MB），之後就不用再下。
- 若你的電腦沒有 NVIDIA 顯示卡（例如 AMD 內顯），會用 CPU 執行，速度較慢（見下方耗時說明）。

遮罩怎麼做（瀏覽器內直接塗，推薦）
----------------------------------
1. 上傳原始照片後，它會自動成為遮罩編輯器的底圖。
2. 用白色筆刷在要修改的位置塗抹（例如只換上衣，就塗上衣範圍）；塗錯可用橡皮擦修掉。
3. 沒塗到的地方會逐位元保留原圖，不會被模型動到。

後備方式：上傳遮罩圖（相容舊流程）
----------------------------------
你也可以用 Windows 小畫家製作遮罩圖後上傳：
- 白色：要讓 AI 重畫的區域
- 黑色：要保持原樣的區域
若編輯器裡已經有塗鴉，會以編輯器為準。

中文指令寫法（會自動翻譯，不用自己翻英文）
------------------------------------------
1. 換衣服：
   將人物上衣更換為黑色合身西裝外套，保留臉部、髮型、姿勢與背景，整體維持真實攝影風格。

2. 背景修改：
   將背景改成現代簡約咖啡廳，光線自然溫暖，保留人物的臉部與服裝不變。

3. 同時換衣服與背景：
   將人物改穿白色襯衫與卡其色風衣，背景改為都會街景，保留原本臉部特徵與手部姿勢，整體呈現時尚寫真風格。

保留內容建議
------------
建議在「保留內容」欄位明確寫出（會接在指示後一起翻譯送出）：
- 保留臉部特徵
- 保留髮型
- 保留背景（如果不想改）
- 保留手部與姿勢
- 保留構圖
提醒：真正的「保留」是靠遮罩保證的；這欄是給模型的額外描述輔助。

Negative Prompt 建議
-------------------
預設已填入加強版（不用自己改）：
blurry, low quality, bad anatomy, bad hands, deformed hands, extra fingers, extra limbs, censored, mosaic

結果存檔
--------
每次生成的每張結果都會自動存到程式同層的 outputs 資料夾：
- edit_日期_時間_序號.png（修圖結果）
- edit_日期_時間_序號.json（該張的完整執行資訊：使用的 prompt、seed、參數、模式）
想重現某張結果，用同一組參數與該張記錄的 seed 即可。

CPU 預期耗時（無 NVIDIA 顯卡時）
--------------------------------
- 預設參數（處理解析度 512、步數 50、一次 2 張）：約數分鐘起一輪，可以按了讓它掛著跑；
  介面會顯示生成進度與目前步數
- 把處理解析度往上調（768／1024）會明顯更久；記憶體不足時先把它調低
- 遮罩模式只重算塗抹區域附近，未編輯區維持原圖畫質，不用為了畫質硬拉全圖解析度

模型清單說明
------------
- 預設模型：stable-diffusion-v1-5/stable-diffusion-inpainting（SD 1.5 Inpainting，公開可下載）。
  （舊的 runwayml/stable-diffusion-inpainting 位址已搬家，故改用新位址。）
- 已移除 stabilityai/stable-diffusion-2-inpainting：該模型需要 Hugging Face 授權（gated），
  本工具沒有登入流程，一般使用者選了只會下載失敗，故自清單移除。
- 不提供 SDXL：SDXL 管線在 CPU 模式需要以 fp32 載入，記憶體需求超過 16GB RAM 筆電可負擔範圍，
  屬不可用選項，故不列入；日後若換有大記憶體或 NVIDIA 顯卡的電腦再評估。

注意事項
--------
- 本工具生成的結果不保證每次都完美，建議用「一次生成張數」一次出 2~4 張不同 seed 挑選。
- 若結果偏差太大，可以：
  1. 縮小修改範圍（把遮罩塗得更精準）
  2. 降低修改強度
  3. 提高保留內容的描述
  4. 更換 seed

常見問題
--------
Q: 啟動很慢？
A: 第一次開啟會下載並預載模型（數 GB），看「模型狀態」欄位即可知道進度，之後開啟就快了。

Q: 生成失敗，說記憶體不足？
A: 降低「處理解析度」或「推論步數」，或把「一次生成張數」改回 1。

Q: 結果和想像差很多？
A: 先確認遮罩範圍是否正確，再調整 prompt；執行資訊裡可看到實際送出的英文 prompt，
   若翻譯不如預期，也可以直接輸入英文指示（英文會原樣送出）。

Q: 換衣服不夠精準？
A: 這是通用修圖模型，不是專門的虛擬試衣模型；若要更精準的衣服版型與紋理，未來可升級成 CatVTON / IDM-VTON 類型工具。
