AI 文字修圖工具（本機版）
==========================

用途
----
1. 上傳原始照片
2. 在瀏覽器裡的遮罩編輯器直接塗出要修改的區域（白色筆刷；也可上傳遮罩圖）
3. 輸入中文修圖指示（會自動翻譯成英文再送給模型）
4. 產生修圖結果，並自動存檔到 outputs 資料夾

核心理念（先講清楚，免得期待落差）
----------------------------------
1. 遮罩就是「指定哪裡能改、哪裡不准動」的工具：
   有塗遮罩時，沒塗到的區域由程式逐位元貼回原圖，絕不變形、不糊化
   ——這是合成方式的架構保證，不是看模型運氣。
   輸出會維持原圖的完整解析度，只有遮罩範圍內會被重畫。
2. 不用遮罩也可以：遮罩留空就是「全圖模式」，任何提示都能改整張圖；
   但全圖重繪時，臉部、手部等細節的保真風險較高，
   建議先用遮罩模式比對效果，滿意再視需要嘗試全圖模式。
3. 中文提示會自動翻譯：修圖模型（SD 1.5）的文字理解只支援英文，
   本工具會先用離線翻譯模型把中文指示翻成英文再送出，
   任何中文描述都能送達模型；中英混寫也可以，英文片段會原樣保留。
   （執行資訊裡會同時顯示你輸入的原文與實際送出的 prompt。）

適合的用途
----------
- 換衣服（例如襯衫、西裝、外套、裙子）
- 改背景（例如咖啡廳、街景、室內攝影棚）
- 改風格（例如寫實、時尚雜誌感）
- 小範圍修圖（例如改掉衣服顏色、改配件）

不一定理想的情況
----------------
- 需要極高精度的人像保真（遮罩外保證不變，但遮罩內的臉、手大改仍受模型世代上限影響）
- 需要直接參考另一張衣服照片精準試穿
- 需要在沒有遮罩的情況下只精準改某一小塊（請改用遮罩指定範圍）

第一次安裝
----------
1. 雙擊 install.bat（會依序找 Python 3.11、3.12、3.13 建立虛擬環境並安裝鎖定版本的套件）
2. 安裝完成後，雙擊 start.bat
3. Chrome 會自動打開 http://127.0.0.1:7860

首次啟動注意事項
----------------
- 第一次開啟頁面時會自動在背景下載並預載修圖模型（數 GB），
  介面右上角的「模型狀態」欄位會顯示進度；也可以按「預先載入模型」手動觸發。
- 第一次使用中文指示時，還會下載離線翻譯模型（約 300 MB），之後就不用再下。
- 若你的電腦沒有 NVIDIA 顯示卡（例如 AMD 內顯），會用 CPU 執行，速度較慢（見下方耗時說明）。

遮罩怎麼做（瀏覽器內直接塗，推薦）
----------------------------------
1. 上傳原始照片後，它會自動成為遮罩編輯器的底圖。
2. 用白色筆刷在要修改的位置塗抹（例如只換上衣，就塗上衣範圍）；塗錯可用橡皮擦修掉。
3. 沒塗到的地方會逐位元保留原圖，不會被模型動到。

後備方式：上傳遮罩圖（相容舊流程）
----------------------------------
你也可以用 Windows 小畫家製作遮罩圖後上傳：
- 白色：要讓 AI 重畫的區域
- 黑色：要保持原樣的區域
若編輯器裡已經有塗鴉，會以編輯器為準。

中文指令寫法（會自動翻譯，不用自己翻英文）
------------------------------------------
1. 換衣服：
   將人物上衣更換為黑色合身西裝外套，保留臉部、髮型、姿勢與背景，整體維持真實攝影風格。

2. 背景修改：
   將背景改成現代簡約咖啡廳，光線自然溫暖，保留人物的臉部與服裝不變。

3. 同時換衣服與背景：
   將人物改穿白色襯衫與卡其色風衣，背景改為都會街景，保留原本臉部特徵與手部姿勢，整體呈現時尚寫真風格。

保留內容建議
------------
建議在「保留內容」欄位明確寫出（會接在指示後一起翻譯送出）：
- 保留臉部特徵
- 保留髮型
- 保留背景（如果不想改）
- 保留手部與姿勢
- 保留構圖
提醒：真正的「保留」是靠遮罩保證的；這欄是給模型的額外描述輔助。

Negative Prompt 建議
-------------------
blurry, low quality, bad anatomy, bad hands, extra fingers, extra limbs, distorted face

結果存檔
--------
每次生成的每張結果都會自動存到程式同層的 outputs 資料夾：
- edit_日期_時間_序號.png（修圖結果）
- edit_日期_時間_序號.json（該張的完整執行資訊：使用的 prompt、seed、參數、模式）
想重現某張結果，用同一組參數與該張記錄的 seed 即可。

CPU 預期耗時（無 NVIDIA 顯卡時）
--------------------------------
- 處理解析度 512：約數分鐘起一張（步數 25 時）
- 處理解析度 768：明顯更久；1024 可能要數十分鐘等級
- 可以按了「開始修圖」就讓它掛著跑；介面會顯示生成進度與目前步數
- 品質優先建議：遮罩模式 + 處理解析度 768、步數 25~35；
  遮罩模式只重算塗抹區域附近，未編輯區維持原圖畫質，不用為了畫質硬拉全圖解析度

模型清單說明
------------
- 預設模型：stable-diffusion-v1-5/stable-diffusion-inpainting（SD 1.5 Inpainting，公開可下載）。
  （舊的 runwayml/stable-diffusion-inpainting 位址已搬家，故改用新位址。）
- 已移除 stabilityai/stable-diffusion-2-inpainting：該模型需要 Hugging Face 授權（gated），
  本工具沒有登入流程，一般使用者選了只會下載失敗，故自清單移除。
- 不提供 SDXL：SDXL 管線在 CPU 模式需要以 fp32 載入，記憶體需求超過 16GB RAM 筆電可負擔範圍，
  屬不可用選項，故不列入；日後若換有大記憶體或 NVIDIA 顯卡的電腦再評估。

注意事項
--------
- 本工具生成的結果不保證每次都完美，建議用「一次生成張數」一次出 2~4 張不同 seed 挑選。
- 若結果偏差太大，可以：
  1. 縮小修改範圍（把遮罩塗得更精準）
  2. 降低修改強度
  3. 提高保留內容的描述
  4. 更換 seed

常見問題
--------
Q: 啟動很慢？
A: 第一次開啟會下載並預載模型（數 GB），看「模型狀態」欄位即可知道進度，之後開啟就快了。

Q: 生成失敗，說記憶體不足？
A: 降低「處理解析度」或「推論步數」，或把「一次生成張數」改回 1。

Q: 結果和想像差很多？
A: 先確認遮罩範圍是否正確，再調整 prompt；執行資訊裡可看到實際送出的英文 prompt，
   若翻譯不如預期，也可以直接輸入英文指示（英文會原樣送出）。

Q: 換衣服不夠精準？
A: 這是通用修圖模型，不是專門的虛擬試衣模型；若要更精準的衣服版型與紋理，未來可升級成 CatVTON / IDM-VTON 類型工具。
